VEHICLESCAN — START HERE

1. Install Python 3.12 and MySQL.
2. Run schema.sql in MySQL.
3. Copy .env.example to .env and check your MySQL settings.
4. Open PowerShell in this folder.
5. Run:
   py -3.12 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python create_admin.py
   python run.py
6. Open http://127.0.0.1:5000
7. Admin login: http://127.0.0.1:5000/admin/login

Do not print QR stickers for real customers until BASE_URL points to a public HTTPS domain.
Read README.md for complete setup, payment, privacy and production notes.
